# OASIS images

Drop the real screenshots in this folder with these names:

| File | Used on | What to capture |
| --- | --- | --- |
| `thumb.png` | `/projects` card | Landing page or the floor (3:2, 1200×800) |
| `hero.png` | `/projects/oasis` hero | Landing page or floor (16:9, 2400×1350) |
| `floor.png` | detail shot | The floor with the room chat open |
| `rooms.png` | detail shot | Room selection / choose a door |
| `chat.png` | detail shot | In-room chat overlay |

The pages already point at these paths, so dropping a file in is the only step. Until then each slot shows its gradient placeholder. Keep screenshots at 2× for crisp rendering on large displays.
