# MetaTrader images

Drop the real screenshots in this folder with these names:

| File | Used on | What to capture |
| --- | --- | --- |
| `thumb.png` | `/projects` card | Live market board (3:2, 1200×800) |
| `hero.png` | `/projects/metatrader` hero | Terminal or landing page (16:9, 2400×1350) |
| `live.png` | detail shot | `/live` market board |
| `performers.png` | detail shot | `/performers` leaderboard |
| `profile.png` | detail shot | `/profile` balance, PnL and trades |

The pages already point at these paths, so dropping a file in is the only step. Until then each slot shows its gradient placeholder. Keep screenshots at 2× for crisp rendering on large displays.
