# CEX images

Drop the real screenshots in this folder with these names:

| File | Used on | What to capture |
| --- | --- | --- |
| `thumb.png` | `/projects` card | Trading terminal (3:2, 1200×800) |
| `hero.png` | `/projects/cex` hero | Terminal with the book and chart (16:9, 2400×1350) |
| `terminal.png` | detail shot | Full trading terminal |
| `orderbook.png` | detail shot | Live depth / trade tape |
| `auth.png` | detail shot | Sign-in or account screen |

The pages already point at these paths, so dropping a file in is the only step. Until then each slot shows its gradient placeholder. Keep screenshots at 2× for crisp rendering on large displays.
